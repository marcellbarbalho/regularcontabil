# Regular Contábil — Website Institucional

> Projeto fictício de demonstração desenvolvido para portfólio de web design e desenvolvimento front-end moderno.

![Preview Regular Contábil](assets/og-image.jpg)

## 📌 Sobre o Projeto

A **Regular Contábil** é uma proposta de landing page institucional de alto padrão voltada para escritórios de contabilidade contemporâneos. O projeto combina estética editorial refinada, tipografia corporativa elegante e microinterações que transmitem credibilidade, solidez e modernidade.

---

## 🚀 Tecnologias Utilizadas

* **HTML5 Semântico:** Estruturação orientada a SEO e acessibilidade.
* **CSS3 Vanilla Moderno:** 
  * Design tokens com variáveis CSS (`--bg-main`, `--text-dark`, `--metal`, etc.).
  * Layout responsivo com Flexbox e CSS Grid.
  * Animações e transições sutis sem dependência de frameworks externos.
  * Tipografias Google Fonts: *Space Grotesk*, *Inter* e *IBM Plex Mono*.
* **JavaScript Vanilla:**
  * Carrossel de fundo com troca sincronizada de conteúdo e autoplay pausável ao passar o mouse.
  * Contadores numéricos dinâmicos com easing exponencial (`easeOutExpo`) acionados por `IntersectionObserver`.
  * Cards de processo com animação staggered em cascata.
  * Acordeão de FAQ expansível/recolhível com cálculo dinâmico de altura.
* **Otimização de Mídia:**
  * Imagens convertidas para o formato `.webp` de alta eficiência.
  * Favicon vetorial em `.svg`.
  * Imagem de Open Graph dedicada para compartilhamento em redes sociais.

## ⚡ Como Rodar Localmente

Como o projeto é construído em front-end puro (HTML/CSS/JS), nenhuma instalação de dependências ou Node.js é necessária:

1. Clone o repositório ou faça o download dos arquivos:
   ```bash
   git clone <URL-DO-SEU-REPOSITORIO>
   cd "Regular Contabil"
   ```

2. Abra o arquivo `index.html` diretamente em seu navegador preferido ou use a extensão **Live Server** no VS Code.

---

## 🌐 Deploy na Vercel

O projeto está 100% pronto para a Vercel com zero configuração adicional:

1. Suba este projeto para um repositório no seu GitHub.
2. Acesse seu painel em [vercel.com](https://vercel.com).
3. Clique em **Add New... > Project** e importe o repositório.
4. Mantenha as configurações padrão (Framework Preset: *Other*, Root Directory: `./`).
5. Clique em **Deploy**. O site estará no ar em segundos com HTTPS automático.
